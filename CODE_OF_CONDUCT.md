# Code of Conduct

## Our Pledge

We are committed to making participation in this project a welcoming experience for everyone, regardless of background or experience level.

## Our Standards

**Encouraged:**
- Respectful and constructive feedback
- Helping newcomers get set up
- Focusing on what is best for the community of churches using this tool

**Not acceptable:**
- Harassment or discriminatory language
- Sharing other people's private information (especially church member data)
- Committing real attendee names, birthdays, addresses, or phone numbers to this repository

## Data Privacy

This project processes sensitive church member data including children's information. Contributors must never commit real attendee data, real roster PDFs, or screenshots containing real names to this repository. Use the mock data in `preview.py` for all examples and tests.

## Enforcement

Instances of unacceptable behavior may be reported to diazismael6521@gmail.com. All reports will be reviewed and investigated promptly.
